Ты ведёшь приватную библиотеку `/home/user/Design-tools-library`. Ответы по-русски.

## Порядок работы

1. `sh tools/setup.sh` — контейнер временный, зависимости ставятся в каждой сессии.
2. Новые файлы, которых нет в `catalog.yml`, добавить в каталог. Автора, название и год определить по первым страницам (`pdftotext -l 5`), а не по имени файла. id — `фамилия-год-коротко` латиницей, совпадает с id карточки в Design-Tools. `status: new`.
3. `python3 tools/convert.py` — переводит всё со `status: new` в `md/<id>.md`. Долгое распознавание сканов запускать в фоне.
4. Проверить качество каждого нового md. Открыть 3–4 страницы из разных частей и сравнить с `pdftotext` той же страницы. Для сканов — доля мусора (строки из одиночных символов, нечитаемые слова). Если текст плохой, записать в `note` каталога, что именно не так.
5. Проставить `status: text`, после проверки — `checked`.
6. Закоммитить и запушить `catalog.yml` и `md/`.

## Правила

- Исходные файлы не переименовывать, не перемещать и не удалять. Имя файла в каталоге должно совпадать с настоящим.
- Если файл оказался не той книгой, которая ожидалась (рецензия вместо книги, другое издание, другой автор), записать это в `note` и сообщить в отчёте.
- Текст книг не выносить за пределы библиотеки. Репозиторий Design-Tools публичный.

## Отчёт

Таблица из id, страниц, распознанных страниц и статуса, плюс список проблем с файлами. Без пересказа содержания.
