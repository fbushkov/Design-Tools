Design Tools — что нового в версии 0.3 (6 ноября 2026)

ТЕСТОВЫЕ РАЗБОРЫ
- Проведены три тестовых разбора через интерфейс приложения: сервисная сеть (KPI и жалобы), ИТ-стартап (основатель решает всё), производство (ИИ-ассистент не прижился). Все сохранены как тестовые в «Моих разборах».
- По итогам: главная проблема в каждом сценарии на первом месте; добавлены синонимы для разговорных описаний (основатель/директор → собственник, «не стыкуются», «по три раза», «тайком» и др.); подходы для ИТ-разработки (метрики DevOps) больше не всплывают в сервисе и производстве; каскад OKR для стартапа на стадии 1 помечается как вредный.

МОИ РАЗБОРЫ
- Фильтр «Все / Реальные / Тестовые».
- «Продолжить» — открыть сохранённый разбор в редакторе со всеми отметками, правками и заметками.
- Блок «Итог»: какой путь выбрали и что получилось.
- «Сделать тестовым / реальным», удаление с подтверждением.
- Повторное сохранение открытого разбора обновляет тот же файл.

РЕГЛАМЕНТ
- Диагностика сгруппирована по адресатам: собственник, руководители, сотрудники, клиенты, данные — вместо десятков шагов.
- Регламент редактируется: изменить пункт (двойной щелчок), удалить, добавить пункт или шаг, переименовать шаг.
- «Из базы» — собрать заново из карточек.
- На шаге проблем показываются 6 самых похожих, остальные — по кнопке «Показать все проблемы».

ИИ-ПОМОЩНИК (НЕОБЯЗАТЕЛЕН)
- Настройки → ИИ-помощник: несколько моделей, выбор активной, проверка подключения, режим «Без ИИ».
- Поддерживаются Claude (Anthropic), OpenAI, OpenRouter, локальные Ollama и LM Studio, любой сервис, совместимый с OpenAI.
- Кнопка «Черновик с ИИ» в регламенте. ИИ опирается только на карточки базы, ставит страницы только если они есть в карточках, остальное помечает «(гипотеза)».
- Ключи хранятся только на компьютере, зашифрованными.

ОФОРМЛЕНИЕ
- Убраны лишние тени: выбранный пункт меню, панели, активный шаг.
- Даты в списке разборов по-русски, имя файла под заголовком.
- Кнопки в заголовках панелей больше не обрезаются.
- Служебные пометки «вопрос выведен конспектором» не попадают в регламент.
- Одна раскрывашка «Подробнее» в рекомендации вместо трёх.

ВЕРСИЯ 0.3.1
- В «Моих разборах» ссылки «с. N» открывают страницу книги, как в карточках.
- Текст страницы книги показывается с оформлением: заголовки, списки, курсив — без значков разметки.

ВЕРСИЯ 0.3.2
- Исправлен выпуск: раньше сборка могла создать два выпуска с одной версией, и программа писала «Cannot find latest.yml». Теперь выпуск создаётся один раз и публикуется только после загрузки всех файлов.

ВЕРСИЯ 0.3.3 — НЕ ТЕРЯТЬ РАБОТУ (по итогам аудита, 11 ноября 2026)
- Сохранённый разбор сразу появляется в «Моих разборах», без кнопки «Перечитать базу».
- Виден статус разбора: «Сохранён в библиотеке» или «Есть несохранённые изменения»; кнопка «Сохранить» становится «Сохранено», когда всё записано.
- «Продолжить» больше не затирает несохранённую работу: программа спрашивает и предлагает вернуться к черновику. Если открыть тот же разбор, в котором есть правки, откроются правки, а не старый файл.
- Смена подхода не стирает регламент: прежний регламент с отметками и заметками откладывается и возвращается, если выбрать этот подход снова.
- «Отправить все в GitHub» работает, когда в GitHub появились новые карточки и книги: программа сначала подтягивает их, потом отправляет. «Отправлять нечего» больше не считается ошибкой. Вместо текста git — понятные сообщения (нет входа, нет связи, не установлен git).
- «Обновить с GitHub» не падает, если есть неотправленные разборы.
- Перед отправкой программа предупреждает, если в редакторе есть несохранённый разбор.
- «Сделать тестовым» и «Сохранить итог» больше не сбрасывают выбранный разбор и прокрутку.

ВЕРСИЯ 0.3.4 — ОФОРМЛЕНИЕ И ПОДСКАЗКИ
- Список «Модель» показывал только «маркетплейс» — исправлено. Моделей теперь шесть: B2B, B2C, B2G, B2B2C (через партнёров), маркетплейс, внутренний заказчик. Можно выбрать несколько.
- У каждого значения в списках «Масштаб», «Модель», «Что продают», «Рынок» — строка с пояснением.
- Значок «?» с пояснением у полей и терминов: режим разбора, тип бизнеса, оси зрелости, траектория, папки базы, ветка, настройки ИИ. Открывается наведением или щелчком.
- Подписи полей вынесены над полями — одинаково во всех формах.
- Короткие слова (предлоги, союзы, местоимения до трёх букв) больше не остаются в конце строки; тире и «с. 12» не разрываются.
- Вопросы «удалить?», «заменить?» — в окнах программы, а не в системных окнах Windows.
- В рекомендациях одна яркая кнопка «Выбрать» вместо десятка; длинный список авторов в «Опоре» сокращён до шести и «ещё N».
- Английские названия осей (management, process…) убраны из интерфейса.
- Вкладка «Карта книги» неактивна, если карты для страницы нет.
- «Мои разборы»: шапка не наезжает на кнопки в узком окне.
