# Design Tools — приложение для Windows

Рабочее место для разборов по базе. Работает на компьютере, данные не уходят в интернет: карточки берутся из `Design-Tools`, тексты книг, карты и разборы — из приватной `Design-tools-library`.

## Что умеет (версия 0.3, ИИ по желанию)

В 0.3: «Мои разборы» с продолжением, итогом, пометкой тестовый/реальный и удалением; редактируемый регламент; необязательный ИИ-помощник (Anthropic, OpenAI-совместимые, Ollama, LM Studio) — см. `docs/izmeneniya-0.3.txt`. Проверки: `tests/smoke.mjs`, `tests/scenarios.mjs`, `tests/ai-mock.mjs`, `tests/safety.mjs` (под `xvfb-run -a node …`, для сценариев и сохранности — с `DT_LIB_DIR` на копию библиотеки) и `npm run test:git` (отправка и обновление на временных репозиториях, запускается и при выпуске). Аудит и план исправлений — `docs/audit-0.3.html`.


- **Разбор.** Ситуация и контекст (масштаб, модель, зрелость по осям, вопросы из `templates/intake.md`) → подбор похожих проблем → вопросы для диагностики → рекомендации-подходы с авторами за и против и пометкой «рано» по зрелости → **регламент** по выбранной рекомендации: шаги с отметками и заметками, критерии успеха, риски, опора. Разбор сохраняется в `Design-tools-library/analyses/`.
- **Карта.** Стадия зрелости управления (по Грейнеру) → направление → проблема → подход с авторами → инструменты → бизнес-результат.
- **Проблемы, подходы, источники.** Поиск, фильтр по категории, карточки со связями.
- **Ссылки на книги.** Любое «(Автор, с. N)» кликается и открывает страницу полного текста книги и раздел карты книги.
- **Разборы.** Список сохранённых разборов и отправка их в GitHub.
- **Поиск по всей базе** — Ctrl+K. Сохранить разбор — Ctrl+S. Листать страницы книги — стрелки. Светлая и тёмная тема.


## Установка

**Обычный способ.** Скачать `Design-Tools-Setup-<версия>.exe` со страницы [Releases](https://github.com/fbushkov/Design-Tools/releases/latest) и установить. Программа сама проверяет обновления при запуске (electron-updater, выпуски на GitHub) и ставит их при перезапуске. База знаний обновляется отдельно — кнопкой «Обновить с GitHub» в настройках.

**Из исходников** (нужны Node.js LTS и git):

```
cd Design-Tools
git pull
cd app
npm install
npm start
```

В приложении: **Настройки → Скачать базу в папку…** или указать существующие папки.

## Выпуск новой версии

1. Поднять `version` в `app/package.json` (например, 0.3.1) и закоммитить в `main`.
2. Поставить метку и отправить её:

   ```
   git tag v0.3.1
   git push origin v0.3.1
   ```

3. GitHub Actions (`.github/workflows/app-release.yml`) соберёт установщик на Windows и опубликует выпуск. Установленные программы скачают его при следующем запуске.

Собрать установщик локально без публикации: `npm run dist`, файл появится в `app\release\`.

## Разработка

- `npm run dev` — интерфейс с горячей перезагрузкой.
- `npm run test:ui` — дымовой тест: запускает приложение, проходит все экраны, сохраняет снимки в `tests/screens/`. На Linux без экрана — через `xvfb-run -a`.
- Папки базы можно задать переменными `DT_BASE_DIR` и `DT_LIB_DIR`.

Устройство: `electron/` — доступ к файлам и git (единственное, что зависит от компьютера; при переходе на веб заменяется сервером), `src/` — интерфейс на React, HeroUI и lucide.
