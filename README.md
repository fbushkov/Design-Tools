# Design Tools

Личная база знаний Филиппа Бушкова о том, как подходить к проблемам бизнеса в стратегии, продукте, сервисе, а также в работе команды с ИИ. Основа — книги, научные работы и собственная практика, переосмысленные под реалии конкретного бизнеса с учётом его зрелости и специфики.

База строится от проблем, а не от книг. Книга сама по себе ничего не решает, решает подход, применённый к нужной проблеме в подходящих условиях.

## Как устроено

| Папка | Что внутри |
|---|---|
| `problems/` | Карточки проблем бизнеса. Симптомы, корневые причины, какие подходы работают на какой зрелости |
| `approaches/` | Подходы и методы (ЦКП, JTBD, сервисный blueprint, OKR…). Суть, условия применимости, где ломается, авторская адаптация |
| `sources/` | Источники. Библиография, свой конспект, ключевые идеи, короткие цитаты со страницами |
| `cases/` | Собственные кейсы без названий клиентов. Что было, что применили, что вышло |
| `templates/` | Шаблоны карточек |
| `taxonomy.md` | Направления, оси зрелости, типы бизнеса и теги — общий словарь для всех карточек |
| `reading-list.md` | Полный список источников по направлениям и категориям проблем |
| `inbox.md` | Источники, которые уже есть под рукой, но ещё не разобраны |
| `ROADMAP.md` | План работ по этапам и текущий этап |
| `gaps.md` | Пробелы базы, из которых выбираются следующие книги |
| `context/ru.md` | Особенности российских компаний и где западные подходы у нас ломаются |
| `tools/check.py` | Проверка карточек: поля по словарю, ссылки, связи в обе стороны |
| `.claude/agents/` | Агенты: библиотекарь, конспектор, куратор, аналитик, проверяющий |

Файлы книг и их полные тексты лежат в приватном репозитории Design-tools-library.

Связи между карточками — обычные относительные ссылки и поля в шапке файла (frontmatter). Проблема ссылается на подходы, подход на источники, кейс на проблему и подходы.

## Как пользоваться

Описать ситуацию клиента свободным текстом и попросить Claude разобрать её по базе. Сначала он задаст недостающие вопросы из `templates/intake.md`, затем ответит по `templates/analysis.md`. Быстрый режим — для подготовки к первой встрече, полный — для диагностики. У каждого тезиса видно, на что он опирается.

## Авторские права

Полные тексты книг и платных статей в репозиторий не кладутся. Только свой конспект, короткие цитаты с указанием страницы и библиография. Открытые научные работы — ссылкой.
